# LINE Split Bill UX Optimization
## Overview
This project focuses on optimizing the Split Bill feature in the LINE application through user research, UX analysis, interface design, prototyping, and usability testing.

The project was developed as a team project for a Human-Computer Interaction course.

The main goal was to identify usability issues in the existing Split Bill experience and propose a more intuitive and structured user flow through the introduction and optimization of the Pre Bill and Split Bill features.

The final solution was developed as an interactive prototype in Figma.

---

## Project Objectives
The project aims to:

- Identify user difficulties when using LINE's Split Bill feature.
- Understand user needs and expectations when dividing bills.
- Analyze the existing user flow and identify opportunities for improvement.
- Design a more intuitive and structured Split Bill experience.
- Introduce the Pre Bill concept to support the ordering and bill-splitting process.
- Validate the proposed design through usability testing.

---

## Problem Statement
Splitting bills after dining with multiple people can become complicated when users need to keep track of individual orders and calculate how much each person should pay.

Although LINE provides a Split Bill feature, the project identified opportunities to improve the overall user experience, particularly in terms of accessing and understanding the Pre Bill and Split Bill flow.

The project therefore explores how the existing experience can be redesigned to make the process more intuitive, structured, and efficient for users.

---

## User Research
User research was conducted to understand how users interact with LINE and their experience with bill-splitting activities.
The research consisted of:
- Questionnaire
- User interviews
- Identification of user needs and pain points

A total of **30 respondents** participated in the questionnaire, while **3 respondents** participated in interviews.
The research focused on:
- Users' familiarity with LINE features.
- Experience using Split Bill.
- Difficulties when dividing bills.
- How users currently manage individual orders.
- Expectations toward a more convenient bill-splitting process.

---

## Research Findings
The research showed that Split Bill is a relevant feature for users, while the overall process still provides opportunities for improvement.

Several findings were identified:
- **83% of respondents** found the Split Bill feature easy to locate.
- **100% of respondents** did not feel disturbed by the introduction of the Pre Bill feature.
- **16.7% of respondents** still experienced difficulties when accessing Pre Bill.
- **100% of respondents** stated that Pre Bill made the ordering process easier.
- Most respondents gave high ratings for the efficiency of the proposed experience.

These findings indicated that the proposed Pre Bill concept was generally well received, while the accessibility and flow of the feature could still be improved.

---

## Design Challenge
Based on the research findings, the main design challenge was:
> How might we make the ordering and bill-splitting process more intuitive, structured, and efficient for LINE users?
The design focused on improving the relationship between **Pre Bill** and **Split Bill** so that users could manage their orders and divide expenses more easily.

---

## Design Solution
The proposed solution introduces and optimizes the **Pre Bill + Split Bill** experience.

### Pre Bill
Pre Bill is designed to support users during the ordering process before the final bill is generated.
The feature helps users keep track of individual orders, making it easier to determine which items belong to each person.

### Split Bill
The Split Bill flow is connected to the Pre Bill process so that users can divide the final payment based on the orders that have already been recorded.
This approach aims to reduce confusion and make the bill-splitting process more organized.
